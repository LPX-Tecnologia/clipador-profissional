# 🎬 Clipador Profissional

Automatize a criação de clipes de vídeo para redes sociais.

## 🚀 Funcionalidades

- Download automático de vídeos do YouTube
- Corte de trechos (até 1 minuto)
- Geração de legendas animadas
- Postagem automática no TikTok e YouTube
- Autenticação OAuth para plataformas
- Painel de controle completo

## 📦 Instalação

```bash
# Clonar repositório
git clone [seu-repositorio]

# Instalar dependências
npm install

# Iniciar desenvolvimento
npm run dev
